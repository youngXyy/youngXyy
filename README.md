## AI，也要讲工程

我更感兴趣的是模型接入之后的问题：

- **知识从哪来**：检索是否准确，答案能否追溯到来源。
- **工具怎么用**：调用有边界，失败可恢复，关键操作可审计。
- **效果怎么评**：建立可复现的评估，观察质量、延迟与成本。
- **上线怎么稳**：关注权限、超时、限流、降级与运行过程的可观测性。

模型可以自信，工程需要证据。

- 用清晰的边界控制复杂度，用测试守住关键行为。
